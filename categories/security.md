# Security & Privacy

VPNs, password managers, encryption tools, firewalls, and ad blockers.

---

### [Mullvad VPN](https://mullvad.net/)
:arrows_counterclockwise: $5/mo flat (no lock-in, cancel anytime, no contract) | Windows, macOS, Linux, iOS, Android
**Replaces:** NordVPN ($4-$15/mo with annual lock-in), ExpressVPN ($7-$13/mo)
Privacy-focused VPN with no accounts -- just a generated number. No email, no personal info required. Pay with cash, crypto, or card. No long-term contracts or annual lock-in; pay month by month with no commitment. Open-source clients and independently audited. Note: this is a monthly service, not a one-time purchase, but is included because it has no subscription lock-in -- you pay only for the months you use.

### [WireGuard](https://www.wireguard.com/)
:unlock: Open source (free) | Windows, macOS, Linux, iOS, Android
**Replaces:** Commercial VPN subscriptions (self-hosted)
Modern, high-performance VPN protocol. Extremely simple to configure, minimal attack surface, and built into the Linux kernel. Set up your own VPN server and never pay a VPN provider again.

### [Bitwarden](https://bitwarden.com/)
:unlock: Open source (free tier, $10/yr premium) | Windows, macOS, Linux, iOS, Android, Web
**Replaces:** 1Password ($3/mo), LastPass ($3/mo)
Password manager with browser extensions, desktop apps, mobile apps, and a web vault. Free tier includes unlimited passwords and devices. Self-hostable with Vaultwarden. End-to-end encrypted.

### [VeraCrypt](https://veracrypt.fr/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** BitLocker alternatives, paid encryption tools
Disk encryption software for creating encrypted volumes or encrypting entire partitions. Based on TrueCrypt with security fixes. Supports AES, Serpent, Twofish, and cascaded encryption. Hidden volumes for plausible deniability.

### [ClamAV](https://www.clamav.net/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Norton ($50/yr), McAfee ($40/yr), Bitdefender ($40/yr)
Antivirus engine for detecting malware, viruses, and trojans. Primarily used on mail servers and for on-demand scanning. Regularly updated virus database. Not a full real-time endpoint solution but effective for targeted scanning.

### [Pi-hole](https://pi-hole.net/)
:unlock: Open source (free, self-hosted) | Linux (Raspberry Pi or any server)
**Replaces:** Ad-blocker subscriptions, DNS filtering services
Network-wide ad and tracker blocking at the DNS level. Protects every device on your network without installing software on each one. Web dashboard for monitoring and configuration.

### [uBlock Origin](https://ublockorigin.com/)
:unlock: Open source (free) | Firefox, Chromium-based browsers
**Replaces:** Paid ad-blocker extensions, AdBlock Plus (with "acceptable ads")
Efficient wide-spectrum content blocker. Blocks ads, trackers, and malware domains with minimal CPU and memory usage. No "acceptable ads" program -- blocks everything you tell it to. The gold standard for browser ad blocking.

### [Little Snitch](https://www.obdev.at/products/littlesnitch/)
:moneybag: $59 one-time | macOS
**Replaces:** Firewall subscriptions, outbound traffic monitoring tools
Application firewall that monitors and controls outbound network connections. Alerts you when applications try to connect to the internet, letting you allow or deny each connection. Network monitor with real-time traffic visualization.
