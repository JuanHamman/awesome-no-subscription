# Utilities

System tools, file management, launchers, window managers, and cleanup utilities.

---

### [AppCleaner](https://freemacsoft.net/appcleaner/)
:free: Free | macOS
**Replaces:** CleanMyMac ($40/yr)
Thoroughly uninstalls applications by finding and removing all associated files, caches, and preferences. Drag an app to AppCleaner and it finds everything the app left behind. Simple, focused, and effective.

### [Stats](https://github.com/exelban/stats)
:unlock: Open source (free) | macOS
**Replaces:** iStat Menus ($12 one-time, subscription for updates)
System monitor in the menu bar showing CPU, GPU, memory, disk, network, battery, and sensor information. Highly customizable widgets with multiple display styles. Native macOS app with minimal resource usage.

### [Ice](https://github.com/jordanbaird/Ice)
:unlock: Open source (free) | macOS
**Replaces:** Bartender ($16 one-time)
Menu bar management tool that hides menu bar items to reduce clutter. Show hidden items on hover or click. Simple, lightweight alternative to Bartender after its controversial acquisition.

### [Flow Launcher](https://www.flowlauncher.com/)
:unlock: Open source (free) | Windows
**Replaces:** Alfred ($34 one-time Powerpack), Spotlight (limited on Windows)
Keystroke launcher for Windows with file search, web search, calculator, system commands, and an extensive plugin system. Fast, customizable, and open source. The Alfred experience on Windows.

### [Raycast](https://www.raycast.com/)
:free: Free for personal use | macOS
**Replaces:** Alfred ($34 one-time Powerpack)
Productivity launcher with clipboard history, snippets, window management, and a growing extension store. The free tier includes all core features. Team features require a subscription but personal use is fully free.

### [BleachBit](https://www.bleachbit.org/)
:unlock: Open source (free) | Windows, Linux
**Replaces:** CCleaner ($30/yr)
System cleaner that frees disk space and protects privacy. Clears cache, cookies, temporary files, and logs for the system and 90+ applications. Includes file shredding for secure deletion.

### [Syncthing](https://syncthing.net/)
:unlock: Open source (free) | Windows, macOS, Linux, Android
**Replaces:** Dropbox ($12/mo), Google Drive ($3/mo)
Continuous file synchronization between devices without cloud servers. Peer-to-peer, encrypted, and private. No accounts, no file size limits, no storage quotas. You control where your data goes.

### [LocalSend](https://localsend.org/)
:unlock: Open source (free) | Windows, macOS, Linux, iOS, Android
**Replaces:** AirDrop (Apple-only), Nearby Share (limited)
Cross-platform file and message sharing over the local network. No internet connection required, no accounts, no servers. Works between any combination of devices. Simple drag-and-drop interface.

### [Rectangle](https://rectangleapp.com/)
:unlock: Open source (free) | macOS
**Replaces:** Magnet ($5 one-time), BetterSnapTool ($3 one-time)
Window management with keyboard shortcuts and snap areas. Drag windows to screen edges to resize, use keyboard shortcuts for precise placement. Customizable shortcuts and snap behavior.

### [Flameshot](https://flameshot.org/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Snagit ($63 one-time), paid screenshot tools
Screenshot tool with built-in annotation. Arrows, text, highlights, blur, and shapes directly on the screenshot. Upload to Imgur or save locally. Powerful yet simple for everyday use.
