# Development

Code editors, Git clients, database tools, API testing, AI coding assistants, and self-hosted platforms.

---

### [VS Code](https://code.visualstudio.com/)
:free: Free | Windows, macOS, Linux
**Replaces:** Sublime Text ($99 one-time), JetBrains IDEs ($25/mo)
Lightweight, extensible code editor with built-in Git support, debugging, IntelliSense, and a massive extension marketplace. Supports virtually every programming language through extensions. Dominant editor in the industry.

### [Neovim](https://neovim.io/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Sublime Text ($99 one-time), paid editors
Hyperextensible terminal-based text editor built on Vim. Lua-based configuration, built-in LSP client, Tree-sitter syntax highlighting, and async plugin architecture. Extremely fast and endlessly customizable.

### [Fork](https://git-fork.com/)
:moneybag: $50 one-time | Windows, macOS
**Replaces:** Tower ($69/yr), GitKraken ($5/mo)
Fast, friendly Git client with an intuitive interface for managing repositories. Interactive rebase, merge conflict resolution, blame, stash management, and image diffs. Clean design without bloat.

### [Beekeeper Studio](https://www.beekeeperstudio.io/)
:unlock: Open source (Community Edition free) | Windows, macOS, Linux
**Replaces:** DataGrip ($25/mo)
Modern SQL editor and database manager supporting MySQL, PostgreSQL, SQLite, SQL Server, and more. Clean interface with query autocomplete, table structure viewer, and data export. Community edition is fully functional.

### [HTTPie Desktop](https://httpie.io/)
:free: Free | Windows, macOS, Linux
**Replaces:** Postman (now SaaS-focused with paid teams)
API testing client with a clean interface for sending HTTP requests, inspecting responses, and organizing collections. Also available as a CLI tool. Local-first without mandatory cloud accounts.

### [Continue.dev](https://continue.dev/)
:unlock: Open source (free) | VS Code, JetBrains
**Replaces:** GitHub Copilot ($10/mo)
AI code assistant that connects to any LLM (local or cloud). Tab autocomplete, chat, inline editing, and codebase context. Works with Ollama for fully local AI coding without sending code to external servers.

### [Ollama](https://ollama.com/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Cloud AI API subscriptions (OpenAI, Anthropic)
Run large language models locally. Supports Llama, Mistral, CodeLlama, and many other models. Simple CLI and API interface. Keeps your code and data completely private with zero recurring costs.

### [DBeaver Community](https://dbeaver.io/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** DataGrip ($25/mo)
Universal database tool supporting 80+ databases. SQL editor with autocomplete, ER diagrams, data transfer, and database comparison. Community edition handles MySQL, PostgreSQL, SQLite, Oracle, and many more.

### [Insomnia](https://insomnia.rest/)
:unlock: Open source (core) | Windows, macOS, Linux
**Replaces:** Postman (now SaaS-focused)
API client for REST, GraphQL, gRPC, and WebSocket testing. Design, debug, and test APIs with environment variables, authentication helpers, and code generation. The open-source core works fully offline.

### [Gitea](https://gitea.io/)
:unlock: Open source (free, self-hosted) | Windows, macOS, Linux
**Replaces:** GitHub ($4/mo per user for teams), GitLab
Lightweight, self-hosted Git service with issue tracking, pull requests, CI/CD, and package registry. Written in Go, runs on minimal resources. Full Git hosting under your control.

### [Meld](https://meldmerge.org/)
:unlock: Open source (free) | Windows, macOS, Linux
**Replaces:** Beyond Compare ($30-$60 one-time)
Visual diff and merge tool for files, directories, and version-controlled projects. Three-way comparison, syntax highlighting, and direct editing within the diff view. Integrates with Git, SVN, and Mercurial.

### [Zed](https://zed.dev/)
:unlock: Open source (free) | macOS, Linux
**Replaces:** VS Code, Sublime Text ($99 one-time)
High-performance code editor built in Rust with native GPU rendering. Collaborative editing, built-in terminal, language server support, and an AI assistant. Extremely fast startup and editing performance.
